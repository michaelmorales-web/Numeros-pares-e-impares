# Numeros-pares-e-impares
Programa en Python que lea 20 números enteros y que imprima cuantos son pares y cuantos son impares

## Análisis

### Variable de entrada
- n

### Procesamiento
- cant_par = 0
- cant_imp = 0
- i = 1, 20
- m = n % 2
- m == 0

### Variables de salida
- cant_par
- cant_imp
